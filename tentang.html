Catatan Utang

Aplikasi pencatatan utang-piutang, pembayaran, cicilan, tagihan, dan laporan pribadi.

Catatan Utang menyediakan akun Firebase dan ruang data privat per akun. Catatan dapat disinkronkan melalui Firebase Realtime Database dan digunakan pada perangkat yang memiliki koneksi internet.

Fitur utama

  • Pencatatan transaksi utang dan piutang.
  • Pencatatan pembayaran dan status tagihan.
  • Laporan serta ekspor dan pemulihan backup.
  • Akses multi-tenant dengan pemisahan data berdasarkan UID akun.

Penyimpanan data

Data disimpan pada Firebase project yang dikonfigurasi untuk aplikasi. Catatan Utang tidak menyediakan lampiran bukti transaksi/foto dan tidak menggunakan Google Drive untuk menyimpan lampiran.

Gunakan aplikasi hanya untuk data yang berhak Anda kelola. Jaga keamanan akun, PIN, perangkat, dan file backup.
